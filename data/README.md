# data

Measured data only: 1v1 calibration CSVs and bench logs worth keeping. Simulated logs are regenerated by the tools and are not kept here.

- **Names:** date, rig and test, e.g. `2026-11-05_1v1_T1.csv`, `2026-12-02_4v4_S1.csv`.
- **Calibration CSV:** header `gap_m,i_chaser_A,i_target_A,force_N`, SI units, force attraction-positive (`docs/CALIBRATION.md`).
- **Bench logs:** the record format of `docs/ICD.md` §5.2.
